# The LED Board, The Sound, And The Bags

## What it is, in plain terms

The board the bags go into is a custom iPlay board. It looks like a black gloss cornhole board with a brushed-metal frame, and it has **LED lights running down both sides**. Most of the time the lights chase down the sides in iPlay cyan. **The moment a bag drops in the hole, the board bursts with light and plays a game-show "ring-in" sound.**

You can see and hear all of it in the preview page (`npm run preview` in `server/` builds it).

## The board

| Part | Spec |
|------|------|
| Deck | 24 x 48 in, glossy black, iPlay mark printed in cyan on the deck |
| Frame | Brushed dark metal, same finish as the iPlay app icon |
| Hole | 6 in wide, centered 9 in from the back edge |
| Side rails | 73 LEDs on each long side (60 LEDs per meter strip) |
| Front edge | 37 LEDs |
| Hole ring | 24 LEDs around the hole |

All of this is data, in `assets/board/led-board.json` (generated by `npm run board` from the server config, so the client and server never disagree). The server also serves it at `GET /api/meta`.

## What the lights do

| Moment | Lights |
|--------|--------|
| Idle | Cyan running lights chase down both side rails (9 LEDs long), a slow glow on the front edge, a small spinner around the hole |
| **Bag drops in the hole** | **Burst for 1.8 s:** all rails and the front edge alternate white and the scoring team's bag color at 3 flashes a second, and the hole ring pulses gold |
| Bag lands on the board / misses | No light change |
| Inning scored | One soft pulse in the scoring team's color |
| Match won | A fast chase in the winner's color and white, 4 s |

**"Flash the moment it drops in" is exact.** The server knows the millisecond each bag drops into the hole (`holeEvents[].tMs` in every throw result) and sends a cue with that time. That covers all three ways in: thrown straight in, slid in, or knocked in later by another bag. The sound and the lights share one cue, so they can't drift apart.

### Safety: flash speed

Strobing faster than three flashes a second can trigger seizures in people with photosensitive epilepsy. The burst is capped at **3 flashes a second**, and there is a **reduced-motion version** (one soft glow, no strobe) for players who have "reduce motion" turned on. The client must use it when the phone asks for less motion, and should offer a setting for it.

## The sound

`assets/audio/cornhole-hit.wav` is an **original** game-show style ring-in: a short buzzer punch, then a bright two-note bell going up (E then B). It is built from scratch in code (`server/tools/sfx.ts`), so there is nothing to license. It is not the audio from any TV show, which is someone else's copyrighted recording.

**Chosen: the two-bell ding (`cornhole-hit-alt-ding.wav`).** The other two are kept in case you change your mind:

| File | Sound |
|------|-------|
| `cornhole-hit.wav` | Buzzer punch, then two bells |
| `cornhole-hit-alt-ding.wav` (**chosen**) | Two bells only, no buzzer |
| `cornhole-hit-alt-buzz.wav` | Longer buzzer with one bell on top |

`bag-thud.wav` plays when a bag lands on the board and `ground-thud.wav` when it hits the grass.

To change the sound, edit `server/tools/sfx.ts` and run `npm run sfx`. A test fails if the committed files don't match the generator.

## The bags

- 6 x 6 in, 16 oz, with a stitched border.
- The **iPlay mark is printed in the center**, about 3.4 in wide.
- Team color comes from the 12-color palette (`docs/visual-camera-plan.md`).
- **White mark on dark bags, black mark on light bags.** Use white for black, red, blue, green, purple, pink, teal and maroon. Use black for white, yellow, orange and sky blue.
- Team B's bags also get a stitched X across the front, so the two teams can be told apart without relying on color.

### Logo files

`assets/logo/iplay-mark-cyan.png`, `-white.png`, `-black.png` are transparent 1024 x 1024 versions of the iPlay "i▶" mark, cut out of the app icon (`iplay-mark-source.jpg`) by `npm run logo`.

**Before the final bag print, get a vector (SVG) version of the mark from a designer.** These PNGs are cut from a raster icon, so their edges are slightly soft when enlarged. They are fine for the game and previews.
